Crea mockups de una interfaz para un tótem turístico llamado “Brújula Digital”, diseñado para una pantalla táctil grande de formato vertical, instalada en un tótem físico de aproximadamente 3 metros de alto. No debe parecer una aplicación móvil. Debe parecer una interfaz de pantalla pública, tipo kiosco/tótem interactivo, pensada para una pantalla táctil grande similar a un televisor o monitor de computador integrado en el tótem.

IMPORTANTE:
- No diseñar una interfaz tipo smartphone.
- No usar proporciones, componentes ni estilos de app móvil.
- La interfaz debe estar pensada para una pantalla táctil grande, visible a distancia y usable por personas de pie.
- Todos los textos visibles de la interfaz deben estar en español.
- No usar Lorem Ipsum.
- El resultado debe ser un conjunto de mockups de pantallas conectadas, no una landing page.

Contexto del proyecto:
“Brújula Digital” es un tótem informativo multilingüe para turistas, diseñado inicialmente para el Observatorio Cruz del Sur, en Combarbalá, Chile. El sistema permite consultar información turística, astronómica, cultural y de servicios locales. El tótem incluye:
- pantalla táctil grande;
- interacción por voz;
- asistente IA;
- posible módulo visual/holográfico como elemento de atracción;
- interfaz accesible y clara para turistas nacionales e internacionales.

Objetivo de diseño:
Diseñar una interfaz moderna, institucional, clara, accesible y turística, con inspiración astronómica y tecnológica. Debe sentirse como un sistema interactivo de orientación turística de alto valor, no como una app móvil común.

Lineamientos visuales:
- Formato vertical tipo tótem/kiosco.
- Botones grandes y fáciles de presionar.
- Tipografía grande y legible a distancia.
- Alto contraste.
- Espaciado amplio.
- Navegación simple.
- Íconos claros.
- Estilo visual moderno, turístico, astronómico e institucional.
- Paleta sugerida: azul oscuro, celeste, blanco, acentos dorados o cian.
- Considerar que el tótem tendrá presencia física importante y un holograma/elemento visual de apoyo, por lo que la interfaz debe verse premium y llamativa.
- La interfaz debe ser apta para público general, incluyendo personas que no dominan la tecnología.

Diseñar las siguientes pantallas:

1. Pantalla de bienvenida
Contenido:
- Título principal: “Brújula Digital”
- Subtítulo: “Bienvenido al Observatorio Cruz del Sur”
- Texto secundario: “Información turística, astronómica y servicios locales”
- Botón principal grande: “Tocar para comenzar”
- Texto de apoyo: “También puedes usar asistencia por voz”
- Incluir una referencia visual al entorno astronómico/turístico.
- Debe ser una pantalla atractiva, clara y de alto impacto visual.

2. Pantalla de selección de idioma
Contenido:
- Título: “Selecciona tu idioma”
- Botones grandes:
  - Español
  - English
  - Português
- Diseño limpio, muy legible y con foco en accesibilidad.

3. Pantalla de carga de interfaz
Contenido:
- Texto principal: “Cargando interfaz…”
- Texto secundario: “Preparando contenido en el idioma seleccionado”
- Diseño simple y coherente con el estilo general.

4. Menú principal
Contenido:
- Título: “Menú principal”
- Tarjetas o botones grandes con iconos para:
  - Observatorio Cruz del Sur
  - Lugares turísticos
  - Mapa e indicaciones
  - Gastronomía y servicios locales
  - Transporte
  - Emergencias
  - Asistente IA
  - Cambiar idioma
  - Finalizar sesión
- Debe verse como menú principal de un tótem, no como menú de app móvil.
- Debe tener navegación muy clara y jerarquía visual fuerte.

5. Pantalla Observatorio Cruz del Sur
Contenido:
- Título: “Observatorio Cruz del Sur”
- Secciones o bloques con:
  - Información astronómica
  - Horarios
  - Actividades disponibles
  - Recomendaciones para visitantes
- Botones:
  - “Ver más información”
  - “Volver al menú”

6. Pantalla Lugares turísticos
Contenido:
- Título: “Lugares turísticos”
- Mostrar tarjetas grandes de atractivos turísticos.
- Cada tarjeta debe incluir:
  - Imagen referencial
  - Nombre del lugar
  - Descripción breve
  - Botón “Ver detalle”
- Botón general: “Volver al menú”

7. Pantalla Detalle de lugar turístico
Contenido:
- Título: “Detalle del lugar”
- Mostrar:
  - Imagen principal grande
  - Descripción del lugar
  - Ubicación
  - Recomendaciones
- Botones:
  - “Volver a lugares turísticos”
  - “Volver al menú”

8. Pantalla Mapa e indicaciones
Contenido:
- Título: “Mapa e indicaciones”
- Espacio visual para un mapa grande.
- Incluir opciones como:
  - “Cómo llegar”
  - “Ver ruta”
  - “Volver al menú”
- Debe priorizar claridad y facilidad de orientación.

9. Pantalla Gastronomía y servicios locales
Contenido:
- Título: “Gastronomía y servicios locales”
- Mostrar categorías o tarjetas grandes para:
  - Restaurantes
  - Alojamientos
  - Comercio local
  - Servicios turísticos
- Botón: “Volver al menú”

10. Pantalla Transporte
Contenido:
- Título: “Transporte”
- Mostrar:
  - Rutas disponibles
  - Horarios
  - Opciones de traslado
  - Información útil para el visitante
- Botón: “Volver al menú”

11. Pantalla Emergencias
Contenido:
- Título: “Emergencias”
- Mostrar tarjetas grandes y muy legibles para:
  - Carabineros
  - Ambulancia
  - Bomberos
  - Municipalidad
  - Asistencia turística
- Botón: “Volver al menú”
- Debe tener una jerarquía visual clara y rápida de entender.

12. Pantalla Asistente IA
Contenido:
- Título: “Asistente IA”
- Interfaz tipo asistente conversacional adaptada a tótem.
- Incluir:
  - botón grande de micrófono;
  - espacio para escribir consulta;
  - preguntas sugeridas:
    - “¿Qué puedo visitar cerca?”
    - “¿Cómo llego al observatorio?”
    - “Recomiéndame restaurantes”
- Botones:
  - “Hacer otra consulta”
  - “Volver al menú”
- Debe verse como una herramienta útil, simple y moderna.

13. Pantalla Respuesta del Asistente IA
Contenido:
- Título: “Respuesta del asistente”
- Mostrar una respuesta clara en español.
- Mantener diseño consistente con la pantalla del asistente.
- Botones:
  - “Hacer otra consulta”
  - “Volver al menú”

14. Pantalla Encuesta breve
Contenido:
- Título: “¿Te resultó útil la información?”
- Opciones grandes:
  - Muy útil
  - Útil
  - Poco útil
  - No útil
- Botón: “Finalizar”
- Debe ser rápida y fácil de responder.

15. Pantalla de cierre
Contenido:
- Texto principal: “Gracias por usar Brújula Digital”
- Texto secundario: “La sesión finalizará automáticamente”
- Luego debe volver a la pantalla de bienvenida.

Flujo esperado:
Pantalla de bienvenida → selección de idioma → carga de interfaz → menú principal → acceso a módulos → regreso al menú o finalización → encuesta → pantalla de cierre → regreso a bienvenida.

Requisitos adicionales:
- Generar múltiples pantallas consistentes entre sí.
- Mantener una misma línea gráfica en todo el sistema.
- Diseñar componentes repetibles consistentes.
- El diseño debe sentirse como un sistema real para tótem interactivo de gran formato.
- Priorizar legibilidad, accesibilidad y claridad por encima de decoración excesiva.
- La experiencia debe ser intuitiva para turistas.
- Debe transmitir innovación, orientación turística y valor tecnológico.
